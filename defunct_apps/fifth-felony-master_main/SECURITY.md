# Security Policy

## Supported Versions

This project does not publish a formal version support matrix. Security fixes are developed against the default branch; users should deploy the latest reviewed release or commit.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** flow on this repository's Security tab when it is enabled. Do not open a public issue with exploit details. If private reporting is unavailable, contact a repository maintainer directly and include a concise description, affected version or commit, and steps to reproduce. Please allow maintainers reasonable time to investigate before public disclosure.
